# 无 NuGet 冒烟测试

在解决方案根目录执行：

```powershell
dotnet run --project tests/SnapTray.SmokeTests -c Release
dotnet run --project tests/SnapTray.SmokeTests -c Release -- --capture
```

第二条命令额外捕获一次当前桌面，验证物理像素尺寸、虚拟桌面边界和显示器数量。图像只在内存中，测试不会保存、打印或上传屏幕图像。

测试范围：

- 配置首次加载、Unicode 路径与自定义快捷键的 JSON 往返、原子替换保存、克隆隔离。
- 损坏 JSON 的默认值恢复、警告与原文备份；非法字段和 null 字段的恢复。
- 合成 144 DPI 位图的负坐标虚拟桌面裁剪、跨显示器选区、全屏裁剪，逐像素检查结果。
- 真实 `RegisterHotKey` 冲突：切换失败保留旧绑定、同一绑定重复设置、成功切换释放旧绑定、销毁释放最终绑定。

配置测试只在唯一临时目录中读写并自动清理，不访问真实 `%AppData%`。测试不修改开机启动注册表或剪贴板，不模拟真实按键。热键测试短暂尝试 Ctrl+Alt+Shift+F9/F10/F11/F6/F7/F8；被其他程序占用时换下一个组合，若不足两个可用组合则明确报告 SKIP。退出码为 0 代表没有失败，仍应检查是否存在跳过项。

这些检查覆盖服务逻辑和 Win32 注册生命周期，不替代交互验收。还需人工验证真实的 100%/150%/200% 混合 DPI、多屏跨屏拖选、保存对话框、贴图拖动、剪贴板粘贴及重启后的自动启动。只有当前电脑实际配置的显示器拓扑可由 `--capture` 验证；合成多屏数据不等于真实混合 DPI 交互验证。
